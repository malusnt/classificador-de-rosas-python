# 🌹 Classificador de Rosas

Projeto de **Machine Learning e Visão Computacional** desenvolvido em Python para identificar três variedades de rosas a partir de fotografias.

## 🎯 Objetivo

Desenvolver um sistema capaz de analisar imagens de rosas e classificá-las automaticamente em três categorias.

## 🌸 Categorias identificadas

- Rosa Negra de Halfeti
- Rosa Azul
- Rosa Amnesia

## 🛠️ Tecnologias utilizadas

- Python
- OpenCV
- Scikit-learn
- NumPy
- Streamlit
- Joblib

## 🧠 Como funciona

1. O usuário envia uma fotografia.
2. O OpenCV processa a imagem.
3. O sistema extrai características de cor utilizando histogramas HSV.
4. O modelo de Machine Learning realiza a classificação.
5. O aplicativo apresenta o resultado e uma estimativa de confiança.

## 📊 Resultados experimentais

- 33 imagens carregadas no treinamento.
- Acurácia experimental de 88,89%.
- Três categorias de rosas.

**Observação:** os resultados são experimentais e foram obtidos com uma base de imagens pequena. A precisão ainda precisa ser validada com mais fotografias independentes.
